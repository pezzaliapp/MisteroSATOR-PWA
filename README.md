# 🌀 Il Mistero del SATOR — Quadrato Magico (PWA)

**Ideato e sviluppato da Alessandro Pezzali — pezzaliAPP (© 2025)**

PWA educativa e ludica ispirata al Quadrato Magico **SATOR AREPO TENET OPERA ROTAS**.

## Istruzioni
- **Quadrato**: seleziona due righe o due colonne per scambiarle. Obiettivo: righe e colonne nell’ordine `SATOR/AREPO/TENET/OPERA/ROTAS`.
- **Lettere**: tocca due celle per scambiarle.
- **Enigma**: croce TENET, N centrale, AΩ.
- **Libero**: swap libero + ruota 90°.
Strumenti: Mescola, Hint, Controlla, Reset.

## Tecnico
HTML/CSS/JS (vanilla), PWA offline-ready, responsive.
