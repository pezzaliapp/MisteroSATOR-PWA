📖 Storia in breve

Il Quadrato SATOR AREPO TENET OPERA ROTAS è un palindromo perfetto attestato fin dall’antichità (Pompei) e ripreso in epoca medievale. Le sue letture spaziano dalla simbolica cristiana (PATER NOSTER con le lettere A/Ω) a interpretazioni numerologiche.

SATOR
AREPO
TENET
OPERA
ROTAS

🎮 Modalità

  • Quadrato: scambia righe o colonne (toggle Righe/Colonne).
  • Lettere: scambia due lettere toccando due celle.
  • Enigma: evidenzia TENET orizz./vert. e, con AΩ, tutte le A e O.
  • Libero: manipola senza vincoli, prova Ruota 90°.
