📖 Storia in breve

Il Quadrato SATOR AREPO TENET OPERA ROTAS è un palindromo perfetto attestato fin dall’antichità (Pompei) e ripreso in epoca medievale. Le sue letture spaziano dalla simbolica cristiana (PATER NOSTER con le lettere A/Ω) a interpretazioni numerologiche.

SATOR
AREPO
TENET
OPERA
ROTAS

🎮 Modalità e istruzioni precise

  1. Quadrato (righe/colonne)
    • Clicca una cella in una riga → tutta la riga si evidenzia.
    • Clicca una cella in un’altra riga per scambiare le due righe.
    • Usa il tasto Righe/Colonne per passare allo scambio colonne.
    • Obiettivo: righe e colonne devono leggere nell’ordine SATOR / AREPO / TENET / OPERA / ROTAS.
    • Consiglio: sistema prima “TENET” al centro, poi allinea le altre.
  2. Lettere (swap per-cella)
    • Tocca una cella (si evidenzia), poi tocca la seconda: si scambiano.
  3. Enigma
    • Evidenzia croce TENET e N centrale; AΩ mostra tutte le A e O.
  4. Libero
    • Swap libero; Ruota 90° ruota l’intera griglia.

Strumenti comuni: Mescola, Hint, Controlla, Reset.
